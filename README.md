# Fitplan · 饮食与训练联动助手

我做 Fitplan，是因为记一顿饭时，我知道自己吃了半碗米饭、两个鸡蛋，却很难说出它们各有多少克。Fitplan 允许用户直接写下这样的描述，根据食物和常见份量估算热量与三大营养素。用户也可以按实际情况调整克数。训练同样支持日常表达，例如“爬坡 45 分钟，坡度 10，速度 4.5”。

记录之后，用户可以接着问：“今晚只有十分钟，也没有器材，适合做什么？”系统会把当天的饮食、已完成的训练和个人目标一并提供给 AI。这样，建议能考虑到用户今天已经做过什么；实际采纳的项目也可以直接记回当天。

每个人关心的变化不同。除了查看体重曲线，用户还可以自己定义指标和目标，例如跟踪腰围、体脂率，或记录每周训练次数。

## 10 分钟复现

**环境**　Windows、Node.js 24（含 npm）和浏览器。项目使用 Node.js 内置模块，无需安装第三方依赖。验证版本为 Node.js 24.14.1、npm 11.11.0。

1. 从 [GitHub 仓库](https://github.com/memo542/fitplan) 下载 ZIP 并解压。在含有 `package.json` 的文件夹中打开 PowerShell。
2. 运行以下命令，保持窗口打开：
   ```powershell
   npm.cmd start
   ```
3. 打开[十月演示空间](http://127.0.0.1:5173/?demo=2026-10#week)。首次进入月报，能看到 **31 天、93 条饮食、31 条训练和 5 个体重测量点**，即表示启动成功。点「每周明细」可查看逐日记录。演示数据与[个人空间](http://127.0.0.1:5173/)分别保存。

到这里即可体验记录、估算、成长足迹和备份恢复。结束体验时，在 PowerShell 中按 Ctrl+C 停止服务。

## 体验 AI 建议

准备一个可用的 DeepSeek API 密钥，以下两种配置方式任选一种。

| 方式 | 优点 | 局限 |
|---|---|---|
| Windows 配置工具 | 双击运行，自动测试连接，密钥由当前 Windows 账户加密保存 | 仅适用于 Windows；更换电脑或账户后需要重新配置。连接测试会产生一次 API 调用 |
| 环境变量文件 | 支持 Windows、macOS 和 Linux，方便更换接口地址、模型和密钥 | 需要手动编辑文件并用指定命令启动；密钥以明文保存在本机文件中 |

**方式一 · Windows 配置工具**
双击项目里的 `配置AI.cmd`，在弹出的窗口粘贴密钥并回车。看到 `Connected. Real model reply:` 和一段回答，即表示连接成功。已经启动的网站可以直接使用。

**方式二 · 环境变量文件**
把 [.env.example](.env.example) 复制一份，放在同一目录并命名为 `.env`。打开副本，将密钥填在 `FITPLAN_AI_KEY=` 的等号后。模板已填好 DeepSeek 的接口地址和模型名。请仅在本机保存含密钥的副本，分享时使用空白模板。

若网站正在运行，先在启动窗口按 Ctrl+C，再在项目目录运行：

```powershell
node --env-file=.env server.mjs
```

**验证效果**
打开[演示日的今日建议](http://127.0.0.1:5173/?demo=2026-10#advice)，输入“根据今天已经做过的运动，给我一个睡前十分钟、不用器材的放松安排”。演示日为 10 月 15 日，当天已快走 30 分钟。可对照回答，再勾选实际完成的项目，到当天的训练记录中核对。点击生成会将输入条件、当天饮食与训练摘要、目标及上一次建议发送给模型。

## 估算依据与数据保存

- 食物库包含 2,253 条食物与做法。份量可以调整，每项可查看估算依据；未识别的食物显示为待估。详见[食物估算依据](docs/食物估算依据.md)及[扩展食品营养数据来源](https://data.gov.tw/dataset/8543)（[整理快照](https://github.com/liao961120/Taiwan-FDA-nutrition)）。
- 运动库包含 1,111 条成人活动。选择匹配强度后，可结合适用年龄、体重和运动时长估算消耗。训练计划与实际完成分别记录。
- 记录保存在当前浏览器空间。迁移设备时，使用「备份与恢复」下载 JSON，在新设备上预览并确认恢复。
