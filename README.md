# Fitplan：饮食与训练联动助手

当前阶段：本地最小页面。无外部依赖，无需 npm install。

## 启动
在本文件夹打开 PowerShell，执行：
```powershell
npm.cmd start
```
浏览器访问 http://127.0.0.1:5173 。按 Ctrl+C 停止服务。
也可以直接用浏览器打开 dist/index.html。服务仅监听本机，不提供手机远程访问。

## 本阶段验收
- 切换今日概览、饮食记录、训练安排、本周回顾四个导航。
- 刷新当前页面，仍显示对应栏目；浏览器后退能返回上一栏目。
- 将浏览器宽度缩小到约 390 像素，确认没有横向溢出。
- 空数据不显示成零热量或零训练；未实现的录入按钮明确禁用。
- 未接入 AI、数据存储、营养计算或真实用户记录。

## 结构
dist/index.html：页面结构；dist/style.css：桌面与手机宽度样式；
dist/app.js：导航与日期；server.mjs：仅用 Node 内置模块的本地服务。
