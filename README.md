# Fitplan：饮食与训练联动助手

本地浏览器应用，使用 HTML/CSS/JavaScript 和 Node 内置 HTTP 服务，无第三方运行依赖。
当前完成记录与基础估算；尚未接入 AI、自动训练计划或完整饮食训练联动。

## 启动
已验证开发工具：Node 24.14.1、npm 11.11.0、Git 2.53.0。
在项目文件夹打开 PowerShell，执行：

```powershell
npm.cmd start
```

浏览器打开 http://127.0.0.1:5173 ，保持终端运行。Ctrl+C 停止。
若页面提示“拒绝连接”，先确认服务仍在运行。端口占用时先查看是否已有同项目服务。
固定使用这个地址，勿混用 localhost、文件打开方式或不同端口；浏览器存储按来源隔离。
服务仅监听本机。手机宽度可通过缩窄浏览器查看，不代表已经支持手机远程访问。
无需安装依赖，也不需要 API 密钥或环境变量。

## 已实现
- 身体数据：身高、当前体重、性别必填；自定义指标可添加删除。
- 目标规划：主要方向必选（减脂/增肌/维持/先记录），目标体重选填，改善方向多选，自定义目标保留。
- 训练：自由填写一个动作，规则提取时长、组次、每侧、kg负重、坡度和速度；核对后保存。保留原文，详细字段可修改。
- 训练计划与实际完成分开，未来训练不能标记已完成；支持修改、删除、按日期查看。
- 饮食：记录已吃/查查热量两模式，共用自由输入框；多项使用逗号分隔。
- 已吃模式自动估算并保存；查询不计入，点击“我吃了”才加入今天。相同日期、餐次、原文防重复。
- 可修改估计克数、重新编辑描述或删除整次饮食记录，汇总随之更新。
- 饮食页按日期汇总，首页显示今天已记录热量；未知部分不当成零。
- 所有个人记录保存在当前浏览器 localStorage，不上传到服务器、代码仓库或模型。

## 估算范围与依据
首批包含白米饭、鸡蛋/煎蛋、全脂/脱脂牛奶、原味无糖/低脂无糖/水果酸奶、苹果、白吐司/全麦面包、煮土豆、熟鸡蛋面。
见 [食物估算依据](docs/食物估算依据.md)。这是有限规则与数据表，不是开放式 AI 识别。
每项显示匹配食物、克数、热量与可展开的来源/假设。碗、盒等默认份量不是实测，支持修改。
不支持的做法或菜品保留为未知项；热量只汇总已识别部分，整次均未知时显示“热量待估”。
旧版手动饮食记录保留原文，不偷偷重算；用户可修改描述后重新估算。
这些是食物参考值和用户目标意向，不是医疗或治疗建议。

## 验收
1. 查询“一碗米饭，两个鸡蛋”：不增加实际记录。
2. 点击“我吃了”：只新增一次，重复点击不重复计入。
3. 修改米饭克数：热量重新计算，刷新仍保留。
4. 修改描述：原记录被替换；取消修改保留原记录。
5. 输入未支持食物：提示未知，不显示零摄入。
6. 新增训练计划，再明确确认完成；刷新后状态保留。
测试请使用示例数据，不将真实健康资料放入截图或公开仓库。

语法检查及模拟 DOM 流程测试，不等同于真实浏览器端到端测试。

## 文件结构
- dist/index.html / style.css / app.js：界面、交互、规则识别和本地存储。
- server.mjs：静态资源服务。
- tests/food-estimator.cjs：饮食解析、换算、查询隔离、编辑及持久化回归检查。
- docs/：开发记录、产品方向与食物数据依据。
